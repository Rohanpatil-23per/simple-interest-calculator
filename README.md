# Simple Interest Calculator

## Description

The Simple Interest Calculator is a simple application that calculates the interest earned on a principal amount for a given rate of interest and period of time.

## Formula

The formula used to calculate Simple Interest is:

**Simple Interest = (Principal × Rate × Time) / 100**

Where:

* **Principal (P)** = Initial amount of money
* **Rate (R)** = Rate of interest per year
* **Time (T)** = Time period in years

## Example

Suppose:

* Principal = ₹10,000
* Rate of Interest = 5%
* Time = 2 years

Using the formula:

**SI = (10000 × 5 × 2) / 100**

**SI = ₹1,000**

Therefore, the Simple Interest is **₹1,000**.

## Features

* Accepts principal amount as input
* Accepts rate of interest as input
* Accepts time period as input
* Calculates simple interest
* Displays the calculated interest

## Input

The calculator requires three values:

1. Principal amount
2. Rate of interest
3. Time period

## Output

The calculator displays the calculated Simple Interest.

## Technologies Used

* HTML
* CSS

## How to Use

1. Enter the principal amount.
2. Enter the rate of interest.
3. Enter the time period in years.
4. Click the calculate button.
5. The calculated simple interest will be displayed.
